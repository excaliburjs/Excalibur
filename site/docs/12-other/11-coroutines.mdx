New `ex.coroutine` for running code that changes over time, useful for modeling complex animation code. It can do a lot of what the Actions API can do, but this is useful when things really get complicated.

## Using Coroutines

Coroutines start immediately when the `coroutine()` function is called. Their updates are scheduled using the excalibur [[Clock]].

Coroutines return a promise when they are complete. You can think of each `yield` as a frame.
  * The result of a yield is the current elapsed time
  * You can yield a number in milliseconds and it will wait that long before resuming
  * You can yield a promise and it will wait until it resolves before resuming
  ```typescript
    const completePromise = coroutine(engine, function * () {
      let elapsed = 0;
      elapsed = yield 200; // frame 1 wait 200 ms before resuming
      elapsed = yield fetch('./some/data.json'); // frame 2
      elapsed = yield; // frame 3
    });
  ```

## Coroutine Timing & Lifecycle

### Default timing is preframe

Coroutines run **preframe** by default — each `yield` resumes at the start of the frame, *before* the
engine tick and scene update. To run a coroutine after the engine tick instead, pass
`timing: 'postframe'`:

```typescript
const co = coroutine(engine, function * () {
  // ... your logic
}, { timing: 'postframe' });
```

The full timing set (from [[Clock]]) is `'preframe'`, `'postframe'`, `'preupdate'`, `'postupdate'`,
`'predraw'`, and `'postdraw'`. `'preframe'` matches the default.

### Coroutines don't stop on actor death

A coroutine is scheduled on the engine [[Clock]] and has no awareness of the actor that started it. Killing
the actor does not cancel the coroutine — it keeps ticking until the generator returns or you explicitly
cancel it. If your coroutine should die with the actor, hold the coroutine handle and call
[[CoroutineInstance.cancel]] (`co.cancel()`) from `kill` or `_prekill`:

```typescript
class MyActor extends ex.Actor {
  private _co: ex.CoroutineInstance;

  onInitialize() {
    this._co = ex.coroutine(this.scene.engine, function * () {
      // ... long-running effect
    });
  }

  public kill() {
    this._co?.cancel();
    super.kill();
  }
}
```

:::note
`coroutine(...)` returns a [[CoroutineInstance]] that is also thenable — you can `await` it for completion
*and* keep the handle to call `.cancel()`, `.isRunning()`, or `.start()`.
:::
