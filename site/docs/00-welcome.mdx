# Welcome to Excalibur!

**[Excalibur](https://github.com/excaliburjs/Excalibur) is a free and open source 2D game engine written in [TypeScript](https://www.typescriptlang.org/).**

We want to make it easy for you to create web-based games, whether you're new to game development or you're an experienced game developer. We take care of all of the boilerplate engine code, cross-platform targeting, and more; use as much or as little as you need!

This page has links to all the places you might want to start learning more about our game engine.

## Before you begin

- **Never made a web game before?** Read through our **[Getting Started documentation](/docs/getting-started)** to build a simple game step-by-step.
- **Curious what else you can make?** Look at the **[Samples](/samples)** collection to see Excalibur in action.
- **Building a new game?** Check out our **[Quickstart guide](/docs/quick-start)**.
- **Want to add Excalibur to an existing project?** Follow our **[Installation guide](/docs/installation)**.
- **Ready to learn more about the Excalibur game engine?** Dive into our **[Engine fundamentals](/docs/engine)**. 
- **Looking for a specific how-to?** Investigate the **[Tutorials section](/docs/category/tutorials)** for practical examples to help you get things done.

## Excalibur's design philosophy

We want Excalibur to be a delightful 2D game development experience for the web, with sensible defaults and flexible customization. Excalibur is intended to be a "batteries included" game engine; you can build your project with minimal boilerplate and configuration, and focus on making the game itself.

## Excalibur is FOSS

The Excalibur game engine is free and open source, and always will be. We welcome any feedback or contributions! If you make something with Excalibur, [let us know](https://github.com/excaliburjs/Excalibur/discussions?discussions_q=category%3A%22Show+and+tell%22). We'd love to see what you build!
