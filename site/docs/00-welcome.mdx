# Welcome to Excalibur!

[Excalibur](https://github.com/excaliburjs/Excalibur) is a **free and open source 2D game engine** written in **[TypeScript](https://www.typescriptlang.org/)**. You can use Excalibur to make 2D games for the web!

We want to make it easy for you to create web-based games, whether you're new to game development or you're an experienced game developer. We take care of all of the boilerplate engine code, cross-platform targeting, and more; use as much or as little as you need!

## Excalibur's Design Philosophy

We want Excalibur to be a delightful 2d game development experience for the web, with sensible defaults and flexible customization. Excalibur is intended to be a "batteries included" game engine; you can build your game with minimal boilerplate and configuration, and we also provide a collection of plugins for additional functionality.

## Excalibur is FOSS

The game engine is free and open-source, and always will be. We welcome any feedback or contributions! If you make something with Excalibur, [let us know](https://github.com/excaliburjs/Excalibur/discussions?discussions_q=category%3A%22Show+and+tell%22). We'd love to see what you build!
