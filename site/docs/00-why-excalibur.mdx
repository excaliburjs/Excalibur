Excalibur is designed to be approachable and powerful, whether you're new to game making or an experienced developer.

## Summary of features

<ul style={{listStyle: 'none', padding: 0 }}>
    <li>🎥 Friendly API based around a theater metaphor of [Scenes](/docs/scenes), [Actors](/docs/actors), and [Actions](/docs/category/actions/)</li>
    <li>📦 Object-Oriented and TypeScript-first for built-in guidance for how to use the engine</li>
    <li>🏃[SpriteSheets](/docs/spritesheets), [Sprites](/docs/sprites), and [Animations](/docs/animation)</li>
    <li>💥 [Collisions](/docs/colliders) with [Arcade](/docs/physics#arcade) and [Realistic](/docs/physics#realistic) Physics</li>
    <li>🧩 [2D TileMaps](/docs/tilemap) and [Isometric TileMaps](/docs/isometric)</li>
    <li>🎨 [Custom shaders](/docs/materials), [post-processing](/docs/postprocessors/) support, and [render plugins](/docs/custom-renderer-plugins)</li>
    <li>🖼️ Optimized performance, including auto-batched draw calls</li>
    <li>🎁 An [Entity-Component-System](/docs/entity-component-system) is waiting backstage for when you need additional customization</li>
</ul>

### Additional tool support

We've implemented integration plugins for a number of popular game development tools.

<ul style={{listStyle: 'none', padding: 0 }}>
  <li>[Tiled level editor](/docs/tiled-plugin)</li>
  <li>[LDtk level editor](/docs/ldtk-plugin)</li>
  <li>[Sprite Fusion level editor](/docs/spritefusion-plugin)</li>
  <li>[Aseprite sprite editor](/docs/aseprite-plugin)</li>
  <li>[jsfxr audio](https://github.com/excaliburjs/sample-jsfxr/)</li>
</ul>


There are a lot of great tools out there to build games on the web and no tool is perfect. Use whatever tools makes you happiest. 😊
