[[ActionsContext.meet|Meet]] can be useful for building tracking projectiles that always reach their target.

This method will cause the entity to move towards another until they are within 1 pixel of each other at a specified speed.

A tolerance optional parameter has been added to increase the range in which the Meet Action is completed.  The default is still 1 pixel.

:::warning

This action could possibly never complete! Any actions chained off of it will not fire until the target is met. You will need to call `.clearActions()` to schedule new actions.

:::

:::warning

`Meet` writes the actor's [[MotionComponent.vel|velocity]] directly every frame and zeroes it on completion
or `stop()`. If you also set velocity elsewhere (custom movement code, a separate action, an integrator
input), `Meet` will clobber it — pick one or the other.

`Meet` does **not** automatically stop when the actor dies. Killing the actor removes it from the
[[ActionsSystem]] queue, but `Meet.stop()` is never invoked, so any velocity state it last wrote lingers on
the [[MotionComponent]]. If you pool or revive actors, call `.clearActions()` (or stop the action explicitly)
from `kill`/`_prekill` so the next rent gets a clean velocity.

:::

```typescript
const missile = new ex.Actor({...});

const target = new ex.Actor({...});

// Track towards the target at 100 pixels/second
missile.actions.meet(target, 100)

```
